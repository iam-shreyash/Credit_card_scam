💳 Credit Card Fraud Detection
This project detects fraudulent credit card transactions using Machine Learning. It applies feature selection to improve model performance and accuracy.

📂 Dataset
Dataset: Credit Card Fraud Detection (https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud?resource=download&select=creditcard.csv)

📈 Usage
Download the dataset and place it in the data/ folder.
Run main.ipynb to perform analysis.
